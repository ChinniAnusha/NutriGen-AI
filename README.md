# NutriGen AI 🥗

Advancing Nutrition Science through GeminiAI

## 🚀 Features

- Personalized 7-Day Meal Planning
- Food Nutrition Analyzer (Macros & Micros)
- Virtual AI Nutrition Coach
- Clean Dashboard UI
- Secure API Integration using Streamlit Secrets

## 🛠 Tech Stack

- Python
- Streamlit
- Google Gemini 2.5 Flash API

## 🔐 API Setup

Create `.streamlit/secrets.toml` and add:

GEMINI_API_KEY = "your_api_key_here"

## ▶ Run Locally

streamlit run app.py
